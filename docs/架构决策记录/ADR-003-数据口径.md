# ADR-003：平台运行结果与外部资料分离

日期：2026-09-02
状态：Accepted

## 决策

本平台源码实际产生的运行结果统一标识为 `ENGINE_RUNTIME_RESULT`，契约验证产物标识为 `ENGINE_EXPERIMENT_RESULT`。外部历史资料只作为独立参考，不进入平台运行数据。

用户口述、推断、合成样例和 UI fixture 不得自动进入正式论文指标。

## 原因

平台运行数据与外部资料的来源、版本和用途不同。将两类数据混合会使论文结论无法复核，也会掩盖平台本身的真实能力。

## 验收要求

每个正式导出指标都必须能够回指：实验定义、runId、原始输入、原始输出、Trace 和哈希；无法回指时显示为不可核验。
