# ADR-003：复现运行结果与历史数据分离

日期：2026-09-02
状态：Accepted

## 决策

本项目源码实际产生的运行结果统一标识为 `REPRODUCED_SYSTEM_RUN`。历史原系统数据只有在原始文件、日志、请求响应或可复核报告存在时，才允许标识为历史原始数据。

用户口述、推断、合成样例和 UI fixture 不得自动进入正式论文指标。

## 原因

原始业务源码不可接入，无法证明内部实现和生产环境等价。将两类数据混合会使论文结论无法复核，也会掩盖复现系统本身的真实能力。

## 验收要求

每个正式导出指标都必须能够回指：实验定义、runId、原始输入、原始输出、Trace 和哈希；无法回指时显示为不可核验。
