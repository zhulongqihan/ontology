# ADR-002：使用 SQLite 作为本地持久化基线

日期：2026-09-02
状态：Accepted

## 背景

JSON 文件适合 v0.2 的单进程演示，但无法提供事务、并发控制、索引、审计查询和稳定的历史记录管理。

## 决策

使用 SQLite + JDBC 作为本地默认数据库，保留 JSON 作为：

- 初始种子导入格式；
- 备份导出格式；
- 论文实验的可审阅交换格式。

数据库迁移采用项目内 SQL 文件和版本表，不把数据库结构隐含在 Java 代码中。

## 后果

- 默认运行仍然不需要外部数据库服务。
- 数据库文件可以随运行目录备份和恢复。
- 需要增加 schema migration、事务、锁和兼容导入测试。
- 不支持把 SQLite 直接当作生产高并发数据库；本阶段目标是本地可运行、可备份和可审阅的工程平台。
