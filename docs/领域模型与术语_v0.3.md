# 柔性引擎领域模型与术语 v0.3

更新时间：2026-09-02

## 1. 核心对象

| 对象 | 含义 | 生命周期 |
| --- | --- | --- |
| Model | 柔性对象模型的身份和顶层配置 | 注册、更新、停用 |
| Schema | 柔性字段集合的不可变版本 | 草稿、发布、废弃 |
| Field | Schema 中的字段约束 | 新增、改名、删除、迁移 |
| Workflow | 状态节点和事件转换 | 草稿、发布、废弃 |
| OntologyType | 本体对象类型 | 注册、更新、停用 |
| Relation | 本体对象之间的有向关系 | 注册、废弃 |
| Service | Provider/Consumer 的可调用注册信息 | 注册、健康、停用 |
| RuntimeContext | 某个模型对象的持续运行上下文 | 创建、运行、完成、失败、回滚 |
| Run | 一次不可变的运行记录 | 创建后只读 |
| Snapshot | 运行前后某一时点的状态和字段 | 创建后只读 |
| Trace | 一次运行的阶段和耗时集合 | 创建后追加、最终封存 |
| AuditEvent | 对配置或运行产生影响的审计事件 | 追加只读 |

## 2. 聚合边界

### Model 聚合

Model 聚合拥有 Schema、Workflow 和本体绑定引用。Model 的版本不是简单的时间戳，而是影响运行语义的配置版本。

### RuntimeContext 聚合

RuntimeContext 拥有当前状态、当前字段值、最后成功运行和版本引用。Run、Snapshot 和 Trace 是上下文产生的不可变历史记录。

### Ontology 聚合

OntologyType 和 Relation 共同决定对象装配规则。关系的目标类型必须可解析，关系名称在来源类型内唯一。

## 3. 关键不变量

1. 已发布 Schema 不允许原地修改。
2. 已完成 Run 不允许修改输入、输出、状态或 Trace。
3. 失败 Run 不得推进 RuntimeContext 的业务状态。
4. 幂等键在同一个作用域内只能对应一个执行结果。
5. 同一 Workflow 状态和事件最多对应一个目标状态。
6. Schema 字段名在同一版本内唯一。
7. Relation 名称在同一来源类型内唯一。
8. 运行记录必须固定引用 Model、Schema 和 Workflow 版本。
9. 所有可写配置变更必须有审计事件。
10. 复现结果和历史原始结果不能共用同一个数据身份。

## 4. 术语约定

- “柔性”指运行模型可以在不修改固定业务表结构的前提下，通过 Schema 版本增加或迁移属性。
- “动态记录”指按字段定义校验的键值记录，不等于任意 JSON 永远合法。
- “上下文连续性”指同一 `contextId` 下的状态和字段可以跨请求恢复。
- “本体装配”指将柔性记录按类型和关系配置投影为领域对象图。
- “复现假设”指没有原始实现可直接证明、但为形成可运行行为而明确记录的设计选择。
- “运行结果”指本项目的执行事实，不自动代表历史原系统的运行事实。
