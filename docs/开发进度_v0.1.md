## 数据口径

当前 `runs/contract-20` 下的数据是本项目代码实际执行产生的 `ENGINE_EXPERIMENT_RESULT`，不是外部生产系统数据，也不是手工填写的模拟结果。

当前前端直接消费 `engine-admin-api` 的运行状态，不再使用静态 `frontend/src/data.ts` 展示快照。管理 API 产生的运行结果是本柔性引擎的真实运行结果，身份标记为 `ENGINE_RUNTIME_RESULT`；契约验证报告使用 `ENGINE_EXPERIMENT_RESULT`，并以 `runs/contract-20` 中带哈希的运行产物为准。
