## 数据口径

当前 `runs/contract-20` 下的数据是本项目代码实际执行产生的 `REPRODUCED_SYSTEM_RUN`，不是原生产系统数据，也不是手工填写的模拟结果。

当前前端直接消费 `engine-admin-api` 的运行状态，不再使用静态 `frontend/src/data.ts` 展示快照。管理 API 产生的运行结果是本复现系统的真实运行结果，身份标记为 `REPRODUCED_SYSTEM_RUN`；它不能冒充原生产系统数据。契约回归报告仍以 `runs/contract-20` 中带哈希的运行产物为准。
