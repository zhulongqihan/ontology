# 实现边界

## 可以提交并复现的内容

- 柔性字段、表单、状态机、快照和版本兼容的独立实现。
- Questionnaire/Subject/Option/JobOntologyDetail 的对象和关系实现。
- 本地 Provider/Consumer 调用和四类契约场景。
- 固定种子实验数据、请求响应、Trace、日志和数据库前后快照。
- 失败注入、重试、回滚和幂等测试。

## 不应声称的内容

- 原始生产源码的逐行还原。
- 原生产环境的注册中心、部署、流量和收益。
- 复现系统数据等于原系统数据。
- 历史 37/37 或 59/1/7 已在当前复现代码中自动重跑。

## 数据身份

新系统真实执行产生的数据使用 `REPRODUCED_SYSTEM_RUN`。没有执行，只存在界面 fixture 的数据使用 `SIMULATED_ONLY`。历史文件使用 `HISTORICAL_RAW` 或 `DERIVED`，用户陈述使用 `USER_REPORTED_PENDING_RAW_RECORD`。
