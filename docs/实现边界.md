# 实现边界（历史基线）

> 本文档保留为 v0.1 的实现边界记录。当前工程需求以 `docs/系统需求规格_v0.3.md`、`docs/领域模型与术语_v0.3.md` 和 `docs/架构决策记录/` 为准。

## 当前可提交的实现内容

- 柔性字段、表单、状态机、快照和版本兼容的独立实现。
- Questionnaire/Subject/Option/JobOntologyDetail 的对象和关系实现。
- 本地 Provider/Consumer 调用和四类契约场景。
- 固定种子配置、请求响应、Trace、日志和数据库状态。
- 当前已覆盖的失败校验和状态迁移测试。

## 不应声称的内容

- 原始生产源码的逐行还原。
- 原生产环境的注册中心、部署、流量和收益。
- 平台运行数据等于任何外部系统的生产数据。
- 尚未执行的历史测试统计可以被当前平台自动重写。

## 数据身份

平台真实执行产生的数据使用 `ENGINE_RUNTIME_RESULT`。契约验证产物使用 `ENGINE_EXPERIMENT_RESULT`。没有执行、只存在于界面 fixture 的数据使用 `SIMULATED_ONLY`；外部资料使用 `EXTERNAL_REFERENCE`。
